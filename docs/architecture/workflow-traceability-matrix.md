## Phase 3 Acceptance Criteria

- Every workflow activity that mutates SRS state writes a domain entity and audit record in one transaction.
- Every workflow side effect to an external system writes or updates an `integration_exchange` row.
- Every human task completion is represented by a workflow event and audit record.
- Every workflow has a test fixture that asserts expected entity/event/contract side effects.
