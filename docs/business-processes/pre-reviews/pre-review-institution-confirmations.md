## Summary

The decisions' defaults are mostly sound and conservative: no academic sanction for debt (D-8, D-18 match CMA182 para 5.49), two-person CAS approval, right-to-study checks for all entrants, consent-led verification, governed EC outcomes. Five shipped behaviours are not safe as defaults for a production tenant. Statutory working-day deadlines skip institutional closure days; built-in rule fallbacks are allowed by default and are undergraduate values applied to every programme; the resit cap fallback escapes the D-35 trace and refusal; the D-12 attempt limit is not enforced at all; and right-to-study scope can be switched off for sponsored students. Six configuration keys in the decision records do not match what the code reads.

Findings: Blocker 0, Major 5, Minor 8, Observation 3.
