# Appraisal Finding Triage Cadence

Appraisal findings are reviewed after every facilitated session and in a consolidated weekly review while appraisal is active. Product/domain, engineering and accessibility responsibility must be represented, even when one person fills several roles.

Every finding receives one disposition: accepted defect, accepted usability improvement, accepted capability gap, duplicate, environment invalidation, rejected with rationale, or scheduled research. Critical security/privacy observations follow the security process immediately and are not held for cadence review.

The review records owner, next action, target capability, evidence link and whether documentation or test coverage must change. Environment-invalidated runs do not contribute to product defect totals.
